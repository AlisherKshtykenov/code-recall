# flatten

**Что делает.** Склеивает несколько осей тензора в одну, не меняя порядок элементов. Типичное место — между свёрточной частью сети и полносвязным слоем: `(batch, каналы, высота, ширина)` → `(batch, каналы·высота·ширина)`.

## Как это делают в жизни

```python
import torch
import torch.nn as nn

x = torch.randn(8, 16, 4, 4)            # выход последнего conv_block
torch.flatten(x, start_dim=1).shape     # (8, 256): batch остаётся, остальное — в одну ось
x.flatten(1)                            # то же методом
nn.Flatten()(x).shape                   # слой: по умолчанию start_dim=1, end_dim=-1 (для nn.Sequential)
```

## Параметры `torch.flatten`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `input` | — | тензор любой формы и dtype |
| `start_dim` | `0` | первая склеиваемая ось (можно отрицательную) |
| `end_dim` | `-1` | последняя склеиваемая ось (включительно) |

## Подводные камни

1. **`torch.flatten` и `nn.Flatten` — разные умолчания.** Функция по умолчанию склеивает и ось batch (`start_dim=0`), слой — нет (`start_dim=1`). `torch.flatten(x)` в модели сольёт весь батч в один вектор.
2. **Вид, а не копия.** Если можно, результат — view того же хранилища: изменение результата меняет исходный тензор. Нужна копия — `.clone()`.
3. **Размер для linear.** `in_features` следующего `linear` = C·H·W; при другом размере картинки он поменяется — считайте его по пробному прогону.
4. **Скаляр** превращается в вектор из одного элемента, а `start_dim == end_dim` возвращает тот же тензор.
