# max_pool2d (max pooling)

**Что делает.** Делит карту признаков на окна (обычно 2×2) и из каждого оставляет максимум. Карта становится меньше (вдвое при окне 2), сеть смотрит «шире», а небольшой сдвиг царапины почти не меняет результат.

Градиент идёт только в тот пиксель окна, который был максимумом (при ничьей — в первый по порядку).

## Как это делают в жизни

```python
import torch.nn as nn
import torch.nn.functional as F

pool = nn.MaxPool2d(kernel_size=2)          # stride по умолчанию = kernel_size
x = pool(feats)                             # (batch, 16, 64, 64) -> (batch, 16, 32, 32)
F.max_pool2d(feats, 2)                      # то же функцией
out, idx = F.max_pool2d(feats, 2, return_indices=True)  # idx — для max_unpool2d (декодеры)
```

## Параметры `torch.nn.functional.max_pool2d`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `input` | — | `(N, C, H, W)` или `(C, H, W)` |
| `kernel_size` | — | размер окна (число или пара) |
| `stride` | `None` | шаг; `None` — равен `kernel_size` (окна не перекрываются) |
| `padding` | `0` | отступ из −∞ по краям; не больше половины окна |
| `dilation` | `1` | расстояние между пикселями окна |
| `ceil_mode` | `False` | `True` — неполное последнее окно тоже считается (размер округляется вверх) |
| `return_indices` | `False` | вернуть и позицию максимума: плоский индекс в H·W входа |

## Подводные камни

1. **Нечётный размер.** 65×65 при окне 2 даёт 32×32 — последний ряд выброшен; `ceil_mode=True` даст 33×33.
2. **Отступ — это −∞, а не 0.** Иначе у отрицательной карты (например, до ReLU) максимумом стал бы отступ.
3. **Ничьи** (часто после ReLU — много нулей) — градиент получает только первый пиксель окна, остальные — 0.
4. **NaN «заражает» окно**: максимум окна с NaN — NaN.
