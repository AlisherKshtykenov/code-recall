# confusion_matrix (матрица ошибок)

**Что делает.** Считает, сколько объектов каждого настоящего класса модель отнесла к каждому классу. Из неё получаются почти все метрики классификации: recall (полнота), precision (точность), f1, accuracy.

## Как применять

### Как это делают в жизни

```python
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay  # готовая матрица и её картинка

y_true = [0, 0, 1, 1, 1]                        # настоящие классы
y_pred = [0, 1, 1, 0, 1]                        # предсказания модели
cm = confusion_matrix(y_true, y_pred)           # [[1, 1], [1, 2]]
tn, fp, fn, tp = cm.ravel()                     # для бинарной задачи — сразу четыре числа
confusion_matrix(y_true, y_pred, normalize="true")  # доли по строкам: recall каждого класса на диагонали
ConfusionMatrixDisplay(cm).plot()               # тепловая карта для отчёта
```


### Параметры `sklearn.metrics.confusion_matrix`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `y_true` | — | настоящие метки |
| `y_pred` | — | предсказанные метки |
| `labels` | `None` | порядок строк и столбцов; лишние классы дают нулевые строки, объекты с метками не из списка не считаются. `None` — все встреченные метки по возрастанию |
| `sample_weight` | `None` | вес каждого объекта (с дробными весами матрица — float) |
| `normalize` | `None` | `"true"` — доли по строкам, `"pred"` — по столбцам, `"all"` — от всех объектов; `None` — счётчики |


### Подводные камни

1. **Строки и столбцы не перепутать.** В sklearn строка — правда, столбец — прогноз; в некоторых книгах наоборот. `ravel()` бинарной матрицы даёт именно `tn, fp, fn, tp`.
2. **Порядок классов.** Для строковых меток порядок алфавитный: у `["ок", "брак"]` первым будет «брак». Задавайте `labels` явно, чтобы TP был там, где вы ждёте.
3. **Класса нет в батче** — матрица станет меньше, и `ravel()` вернёт не 4 числа. На валидации всегда передавайте `labels=[0, 1]`.
4. **`normalize` при пустой строке** даёт 0, а не NaN — «нет объектов» и «все ошибочны» выглядят одинаково. Смотрите и счётчики.

## Как работает

Строка — настоящий класс, столбец — предсказанный. Для двух классов «норма = 0, брак = 1»:

| | предсказано 0 | предсказано 1 |
|---|---|---|
| **на самом деле 0** | TN (верно: норма) | FP (ложная тревога) |
| **на самом деле 1** | FN (пропущенный брак) | TP (найденный брак) |

**Идея.** Таблица «правда × прогноз»: в клетке — сколько объектов класса из строки модель отнесла к классу из столбца.

1. Список классов: `labels` или все встреченные метки по возрастанию.
2. Каждой метке — номер строки/столбца; объекты с метками не из списка пропускаем.
3. Для каждого объекта прибавляем его вес в клетку (правда, прогноз).
4. `normalize`: делим на суммы строк (`true`), столбцов (`pred`) или на всё (`all`); 0/0 → 0.

## Задача

**Режим «Библиотека»** — примените `sklearn.metrics.confusion_matrix` с той же сигнатурой, что в «С нуля»: тесты проверяют, что вызвано `confusion_matrix`; в `confusion_matrix(…)` явно передайте `labels=`. Это учит, как и где применять.

**Режим «С нуля»** — напишите `confusion_matrix` своими руками в `solution.py` — та же сигнатура, тот же результат и тот же dtype, что у sklearn.
Можно numpy (`unique`, `isin`, `add.at`, индексация, суммы). Нельзя `sklearn`, `pandas.crosstab`, `np.bincount`, `np.histogram2d`.
В конце файла — `metric = confusion_matrix`: кирпичик реализует слот **metric**.

Общие тесты (сравнение с библиотекой на многих случаях) должны пройти оба режима.
