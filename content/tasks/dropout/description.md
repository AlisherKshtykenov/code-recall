# dropout

**Что делает.** Во время обучения случайно «выключает» часть нейронов (обнуляет с вероятностью p), а оставшиеся усиливает в 1/(1 − p) раз. Сеть не может полагаться на отдельные нейроны и меньше переобучается. На инференсе dropout ничего не делает.

## Как это делают в жизни

```python
import torch.nn as nn
import torch.nn.functional as F

head = nn.Sequential(nn.Flatten(), nn.Dropout(p=0.5), nn.Linear(256, 1))  # dropout перед последним слоем
model.train()   # dropout включён
model.eval()    # dropout выключен: выход детерминирован

F.dropout(x, p=0.5, training=self.training)  # функцией — не забыть передать training!
```

## Параметры `torch.nn.functional.dropout`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `input` | — | тензор любой формы |
| `p` | `0.5` | вероятность обнулить элемент, от 0 до 1 |
| `training` | `True` | `False` — вернуть вход без изменений |
| `inplace` | `False` | изменить сам вход |

## Подводные камни

1. **`F.dropout` по умолчанию в режиме обучения.** В `forward` пишите `F.dropout(x, p, training=self.training)`, иначе dropout работает и на инференсе. Слой `nn.Dropout` сам следит за `train()/eval()`.
2. **Масштаб в обучении, а не на инференсе** («inverted dropout»): на инференсе умножать ничего не нужно.
3. **Dropout перед BatchNorm** портит статистики батча — ставьте его ближе к выходу.
4. **Случайность.** Для повторяемых экспериментов фиксируйте `torch.manual_seed`; маска новая на каждом шаге.

## Задача

Напишите `dropout(input, p=0.5, training=True, inplace=False)` своими руками в `solution.py`. Маска случайная, поэтому тесты проверяют свойства: eval и p = 0 возвращают тот же тензор, доля нулей ≈ p, масштаб 1/(1 − p), градиент — маска/(1 − p), seed повторяем, ошибки как у torch.
Можно `torch.rand_like`, сравнения, умножение. Нельзя `torch.nn` и готовые dropout-функции.
