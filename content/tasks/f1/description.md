# f1 (F1-мера)

**Что делает.** Одно число, которое высоко, только если модель и находит объекты класса (recall, полнота), и не поднимает ложных тревог (precision, точность). Это гармоническое среднее двух метрик.

$$F_1 = \frac{2 \cdot P \cdot R}{P + R} = \frac{2\,TP}{2\,TP + FP + FN}$$

## Как это делают в жизни

```python
from sklearn.metrics import f1_score, classification_report  # готовая метрика и сводный отчёт

y_true = [1, 0, 1, 1, 0, 1]                     # 1 — брак, 0 — норма
y_pred = [1, 1, 0, 1, 0, 1]                     # предсказания модели
f1_score(y_true, y_pred)                        # 0.75: P = 3/4, R = 3/4
f1_score(y_mc_true, y_mc_pred, average="macro") # несколько классов: среднее F1 по классам
print(classification_report(y_true, y_pred))    # precision, recall, f1 и support по каждому классу
```

## Параметры `sklearn.metrics.f1_score`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `y_true`, `y_pred` | — | настоящие и предсказанные метки (не вероятности) |
| `labels` | `None` | какие классы считать и в каком порядке |
| `pos_label` | `1` | положительный класс при `average="binary"` |
| `average` | `"binary"` | `None` — по классам; `"micro"` — из общих TP, FP, FN (для одноклассовой разметки равна accuracy); `"macro"` — среднее по классам; `"weighted"` — взвешенное числом объектов класса |
| `sample_weight` | `None` | вес каждого объекта |
| `zero_division` | `"warn"` | значение, если нет ни настоящих, ни предсказанных объектов класса: `"warn"` (0 + предупреждение), `0`, `1`, `np.nan` |

## Подводные камни

1. **`micro` на мультиклассе = accuracy.** Для дисбаланса классов это бесполезно, смотрите `macro`.
2. **F1 не видит TN.** Сколько верно названо «нормой», F1 не учитывает: на редком браке это плюс, но сравнивать модели по F1 на разных выборках нельзя.
3. **Порог.** F1 считается по меткам, а значит, зависит от порога вероятности (по умолчанию 0.5). Подберите порог на валидации или смотрите `pr_auc`.
4. **Пустой класс в батче** даёт 0 с предупреждением. Считайте F1 по всей валидации, а не средним по батчам.
