# sigmoid

**Что делает.** Превращает любое число в число от 0 до 1. На выходе бинарного классификатора делает из логита (сырой оценки) вероятность: «насколько модель уверена, что это брак».

$$\sigma(x) = \frac{1}{1 + e^{-x}}, \qquad \sigma'(x) = \sigma(x)\,(1 - \sigma(x))$$

## Как это делают в жизни

```python
import torch

logits = model(images)                  # сырые оценки сети, (batch, 1)
probs = torch.sigmoid(logits)           # вероятности брака в [0, 1]
pred = (probs > 0.5).long()             # метка по порогу 0.5

# для обучения sigmoid отдельно НЕ применяют: BCEWithLogitsLoss делает её внутри устойчиво
loss = torch.nn.BCEWithLogitsLoss()(logits, targets)
```

## Устойчивость при больших |x|

Наивная формула `1 / (1 + exp(-x))` при `x = −1000` считает `exp(1000) = inf` — результат ещё верный (0), но градиент становится `inf/inf = NaN`. Решение: всегда брать `exp(−|x|) ≤ 1`:

- при x ≥ 0: $\sigma(x) = 1 / (1 + e^{-x})$;
- при x < 0: $\sigma(x) = e^{x} / (1 + e^{x})$.

Обе ветки используют только $e^{-|x|}$, переполнения нет ни в значении, ни в градиенте. Только $-|x|$ пишите через `where(x >= 0, -x, x)`, а не `abs`: у `abs` в нуле градиент 0, и $\sigma'(0)$ получится 0 вместо 0.25.

## Подводные камни

1. **Не ставьте sigmoid перед BCELoss.** Связка `sigmoid` + `BCELoss` неустойчива при уверенных ошибках; `BCEWithLogitsLoss` (и наш `weighted_cross_entropy`) получает логиты и считает log-sigmoid точно.
2. **Насыщение.** При |x| > 10 градиент почти 0: глубокие сети на sigmoid в скрытых слоях учатся плохо — там ставят ReLU.
3. **float16.** `sigmoid` в половинной точности при |x| > 11 даёт ровно 0 или 1 — `log(0)` в потерях даст inf.
4. **Порог 0.5 не обязателен.** При дисбалансе классов (10% брака) лучший порог подбирают на валидации по recall/f1.
