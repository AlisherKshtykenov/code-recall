# pr_auc (average precision, площадь под PR-кривой)

**Что делает.** Оценивает, насколько хорошо модель ставит настоящие объекты класса (брак) выше остальных — сразу для всех порогов. Это средняя precision (точность) по всем порогам, взвешенная приростом recall (полноты).

$$AP = \sum_k (R_k - R_{k-1}) \cdot P_k$$

Пороги идут от самой высокой оценки к самой низкой; $P_k$ и $R_k$ — точность и полнота, если всё с оценкой ≥ k-го порога назвать браком.

## Как это делают в жизни

```python
from sklearn.metrics import average_precision_score, PrecisionRecallDisplay  # метрика и график

y_true = [0, 0, 1, 1]                           # 1 — брак
y_score = [0.1, 0.4, 0.35, 0.8]                 # вероятность брака (или логит — важен только порядок)
average_precision_score(y_true, y_score)        # 0.83
PrecisionRecallDisplay.from_predictions(y_true, y_score)  # PR-кривая для отчёта

# несколько классов: оценки формы (n, n_classes), один-против-остальных
average_precision_score(y_mc, scores, average="macro")
```

## Параметры `sklearn.metrics.average_precision_score`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `y_true` | — | метки: бинарные, мультикласс (с оценками `(n, n_classes)`) или multilabel-матрица 0/1 |
| `y_score` | — | оценки: вероятности, логиты, расстояния — важен только порядок |
| `average` | `"macro"` | для мультикласса и multilabel: `None` — по классам, `"macro"` — среднее, `"weighted"` — по числу объектов класса, `"micro"` — все пары (объект, класс) вместе, `"samples"` — среднее по объектам. Для бинарной задачи не влияет |
| `pos_label` | `1` | положительный класс в бинарной задаче (в мультиклассе — только 1) |
| `sample_weight` | `None` | вес каждого объекта |

## Почему не трапеции

PR-кривую нельзя интерполировать прямой между точками: precision между двумя порогами не меняется линейно, и трапеции (`auc(recall, precision)`) **завышают** площадь, особенно когда у кривой «зубцы». Average precision — честная ступенчатая сумма: каждый прирост полноты умножается на точность в той точке, где он получен.

## Подводные камни

1. **Передавайте оценки, а не метки.** `average_precision_score(y, model.predict(X))` — это AP одной точки. Нужны `predict_proba(X)[:, 1]` или логиты.
2. **Базовый уровень — доля класса, а не 0.5.** Случайная модель при 10% брака даёт AP ≈ 0.1. Сравнивайте с ней, а не с половиной.
3. **Ничьи в оценках** — одна точка кривой: все объекты с одинаковой оценкой попадают за порог вместе. Сильное округление вероятностей занижает AP.
4. **Нет положительных** — AP = 0 с предупреждением. Считайте на всей валидации, а не по батчам.
