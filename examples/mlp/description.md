# MLP-классификатор на PyTorch

В `data/points.csv` — 400 точек двух переплетённых спиралей (`x1, x2, label`).

- `data_utils.py` **дан**: `load_points(path)` возвращает тензоры `X` формы $(N, 2)$ и `y` формы $(N,)$.
- `model.py` — класс `MLP(in_dim=2, hidden=32, out_dim=2)`: два скрытых слоя `Linear + ReLU`
  и выходной `Linear` (логиты). Всего параметров: $2\cdot32+32 + 32\cdot32+32 + 32\cdot2+2 = 1218$.
- `train.py` — функция `train(model, X, y, steps=200, lr=0.05)`: оптимизатор Adam,
  `cross_entropy`, на каждом шаге — полный батч; возвращает список значений лосса по шагам.
  При запуске: обучить, напечатать точность, показать график лосса, сохранить веса в `results/mlp.pt`.

Тесты проверяют форму выхода, число параметров и то, что лосс падает за 20 шагов на срезе данных.
