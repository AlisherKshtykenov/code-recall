# Быстрая сортировка

Напишите функцию `quicksort(arr)`, которая возвращает **новый** отсортированный список,
не изменяя исходный.

- Выберите опорный элемент (pivot), разделите список на три части: `< pivot`, `== pivot`, `> pivot`.
- Рекурсивно отсортируйте левую и правую части.

Средняя сложность — $O(n \log n)$, худшая — $O(n^2)$.
