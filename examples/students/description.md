# Анализ оценок студентов

В `data/students.csv` — оценки студентов по предметам. Данные грязные: лишние пробелы
и разный регистр в названиях групп и именах, пропуски, оценки вне диапазона 0–100, дубликаты.

Напишите в `analysis.py` три функции:

1. `load(path="data/students.csv")` — прочитать CSV в DataFrame.
2. `clean(df)` — убрать строки без оценки и с оценкой вне $[0, 100]$; привести имена к виду без
   пробелов по краям, группы — к нижнему регистру без пробелов; убрать полные дубликаты.
3. `summary(df)` — таблица по группам (индекс `group`): `students` — число разных студентов,
   `mean_score` — средняя оценка (округлить до 1 знака), `best` — лучшая оценка.
   Отсортировать по `mean_score` по убыванию.

Запуск `analysis.py` показывает таблицы через `show()` и столбчатый график средних.
